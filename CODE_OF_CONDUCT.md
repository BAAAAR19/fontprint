# Code of conduct

## Our standard

This project exists to study typography and document evidence, not people. Everyone
participating — issues, pull requests, discussions — is expected to keep the work
technical, specific, and respectful.

Expected behaviour:

- Critique code, methods, and metrics rather than the person who wrote them.
- Assume good faith when a result disagrees with yours; ask for the seed and font set.
- Respect the privacy rules in [SECURITY.md](SECURITY.md): no real documents, personal
  data, or proprietary fonts in issues, pull requests, or test fixtures.

Unacceptable behaviour includes harassment, personal attacks, publishing others' private
information, and using this project to build or promote tooling that accuses individuals
of fraud without human review.

## Scope and enforcement

This applies in all project spaces and when representing the project publicly. Report
concerns through GitHub's private vulnerability reporting or by contacting the maintainer
directly. Reports are handled confidentially. Maintainers may edit, hide, or remove
contributions, and may block accounts, when behaviour does not meet this standard.

This document adapts the spirit of the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1, condensed for a single-maintainer research repository.
